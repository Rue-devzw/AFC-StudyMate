This page publishes the current StudyMate mobile release so the app can verify its installed version and help users check for updates in-app.

Current Release

Version 1

App version: 1.0.0 (build 1)

Release date: March 21, 2026

Version 1 is the first Android and iPhone release of StudyMate, built around a local-first study experience with optional Google Drive backup.

What’s Included

  • Sunday School and lesson reading flows
  • Bible reading, bookmarks, highlights, and notes
  • Journal and memory verse tools
  • Teacher roster and attendance support
  • Local reminder scheduling
  • Optional Google Drive backup using the signed-in user’s own Drive app data folder

Update Guidance

If StudyMate tells you that a newer build is available, use the official distribution channel provided by AFM SEAR or the app publisher for your platform.

Visit AFM SEAR Website Privacy Policy

Technical Notes

  • Supported platforms: Android and iPhone
  • Current minimum supported build: 1
  • Realtime cloud sync is not part of Version 1
  • Google Drive backup is optional and user-owned
